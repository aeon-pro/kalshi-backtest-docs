## 1. Create an API key

1. Log in at [kalshibacktest.com](https://kalshibacktest.com/login).
2. Open the [Dashboard](https://kalshibacktest.com/dashboard) → **API Keys**.
3. Click **Create New Key**, name it, and copy the key immediately - it is
   only shown once.

<Warning>
Keys are stored as SHA-256 hashes. Lose the raw value and you have to
revoke and re-issue.
</Warning>

## 2. Authenticate

Every request takes either header:

```bash
# Authorization header (recommended)
curl "https://api.kalshibacktest.com/v1/btc/15m/markets?limit=5" \
  -H "Authorization: Bearer kbt_your_api_key_here"

# or X-API-Key
curl "https://api.kalshibacktest.com/v1/btc/15m/markets?limit=5" \
  -H "X-API-Key: kbt_your_api_key_here"
```

## 3. Supported deployments

Five coins, all at 15m:

| Coin | `coin` | `type` | URL prefix |
| :--- | :--- | :--- | :--- |
| Bitcoin  | `btc`  | `15m` | `/v1/btc/15m`  |
| Ethereum | `eth`  | `15m` | `/v1/eth/15m`  |
| Solana   | `sol`  | `15m` | `/v1/sol/15m`  |
| Dogecoin | `doge` | `15m` | `/v1/doge/15m` |
| Ripple   | `xrp`  | `15m` | `/v1/xrp/15m`  |

## 4. Pull a market + its snapshots

```bash
# Latest 5 BTC 15m markets
curl "https://api.kalshibacktest.com/v1/btc/15m/markets?limit=5" \
  -H "X-API-Key: kbt_your_api_key_here"

# One market by its Kalshi ticker
curl "https://api.kalshibacktest.com/v1/btc/15m/markets/KXBTC15M-26APR221830-T105000" \
  -H "X-API-Key: kbt_your_api_key_here"

# Stream snapshots ASC with full orderbook depth
curl "https://api.kalshibacktest.com/v1/btc/15m/markets/KXBTC15M-26APR221830-T105000/snapshots?include_orderbook=true&limit=500" \
  -H "X-API-Key: kbt_your_api_key_here"

# Snapshot closest to a specific wall-clock moment
curl "https://api.kalshibacktest.com/v1/btc/15m/markets/KXBTC15M-26APR221830-T105000/snapshots/at/2026-04-22T18:20:00Z" \
  -H "X-API-Key: kbt_your_api_key_here"
```

## 5. Wire it into code

```python
import httpx, os

BASE = "https://api.kalshibacktest.com"
KEY  = os.environ["KBT_API_KEY"]

with httpx.Client(base_url=BASE, headers={"X-API-Key": KEY}, timeout=30) as c:
    markets = c.get("/v1/btc/15m/markets", params={"limit": 10}).json()
    for m in markets["data"]:
        snapshots = c.get(
            f"/v1/btc/15m/markets/{m['market_ticker']}/snapshots",
            params={"limit": 1000, "include_orderbook": True},
        ).json()
        # ... replay, score, write results ...
```

<Tip>
Responses include `pagination.next_cursor` when there is more to fetch.
Pass it as `?cursor=...` on the next request and stop when
`has_more === false`.
</Tip>
