## Welcome to KalshiBackTest

KalshiBackTest gives quants, systematic traders, and researchers a
stable, read-only API over every Kalshi up/down crypto market we
capture. Each supported (coin × type) deployment streams full orderbook
snapshots ~100 ms apart from market open through settlement, so you can
replay any market tick-by-tick.

## Quick examples

List the most recent BTC 15m markets:

```bash
curl "https://api.kalshibacktest.com/v1/btc/15m/markets?limit=10" \
  -H "Authorization: Bearer kbt_your_api_key_here"
```

Pull full-depth snapshots for one market:

```bash
curl "https://api.kalshibacktest.com/v1/btc/15m/markets/KXBTC15M-26APR221830-T105000/snapshots?include_orderbook=true&limit=500" \
  -H "X-API-Key: kbt_your_api_key_here"
```

Grab the exact snapshot at a moment in time:

```bash
curl "https://api.kalshibacktest.com/v1/btc/15m/markets/KXBTC15M-26APR221830-T105000/snapshots/at/2026-04-22T18:20:00Z" \
  -H "X-API-Key: kbt_your_api_key_here"
```

<Info>
v1 puts the coin **and** the market type in the URL path
(`/v1/{coin}/{type}/...`). One Kalshi Workers Postgres deployment
backs each (coin, type) pair. Today we ship five deployments —
`btc`, `eth`, `sol`, `doge`, `xrp`, all at `15m`.
</Info>

<Note>
Every response uses the v1 envelope — `{ data, pagination?, meta }` for
success, `{ error, meta }` for errors. See the [v1 Overview](/api-reference/v1/overview)
for the full contract.
</Note>
