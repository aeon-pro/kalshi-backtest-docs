## Welcome

The KalshiBackTest v1 API exposes two resource families for each
(coin × type) deployment:

1. **Markets** — stable metadata keyed by `market_ticker`.
2. **Snapshots** — sub-second orderbook + coin-price captures.

That's it. No batch endpoint, no price feed endpoints, no discovery
endpoint — the v1 surface is deliberately narrow so the contract is
easy to hold in your head.

## Base URL

```
https://api.kalshibacktest.com
```

## Authentication

```http
x-api-key: kbt_...
```
*OR*
```http
Authorization: Bearer kbt_...
```

See [Authorization](/api-reference/authorization) for details.
