## Rate limits

Rate limits are per account and enforced with a per-second burst bucket and a
per-minute sustained bucket. All API keys on one account consume the same two
buckets.

<Info>
Free keys can still access all five deployments
(`btc:15m`, `eth:15m`, `sol:15m`, `doge:15m`, `xrp:15m`), but only the
newest 50 markets in each deployment and are also capped at 31 days. Every
shared paid configuration can access all markets inside its purchased 31-,
60-, or 90-day window.
</Info>

### Rate limit headers

Every authenticated response carries:

- `X-RateLimit-Limit` - the tightest active cap (per second or per minute, whichever you were closer to).
- `X-RateLimit-Remaining` - how many slots you have left against that cap.
- `Retry-After` - only on `429` responses; seconds to wait.

### 429 responses

```json
{
  "error": {
    "code": "RATE_LIMIT_BURST",
    "message": "This account exceeded its effective second request limit.",
    "details": {
      "retry_after": 1,
      "limit": 10,
      "window": "second",
      "rate_limit_per_second": 10,
      "rate_limit_per_minute": 300,
      "scope": "account",
      "guidance": "Retry after the indicated delay or select a higher RPS configuration in Billing."
    }
  },
  "meta": { "request_id": "req_a1b2c3d4e5f6", "timestamp": "2026-04-24T18:00:00Z" }
}
```

```json
{
  "error": {
    "code": "RATE_LIMIT_SUSTAINED",
    "message": "This account exceeded its effective minute request limit.",
    "details": { "retry_after": 47, "limit": 300, "window": "minute", "rate_limit_per_second": 10, "rate_limit_per_minute": 300, "scope": "account", "guidance": "Retry after the indicated delay or select a higher RPS configuration in Billing." }
  },
  "meta": { "request_id": "req_...", "timestamp": "2026-04-24T18:00:00Z" }
}
```

Branch on `error.code`, not `error.message`.

<Tip>
When you see `RATE_LIMIT_BURST`, back off for `details.retry_after`
seconds (always `1`) before retrying. For `RATE_LIMIT_SUSTAINED`, the
value is whatever's left of the current minute.
</Tip>

<Warning>
If you use multiple API keys concurrently, coordinate retries across the whole
account. Each key sees and consumes the same purchased capacity.
</Warning>
